# Dynamic Employee Dashboard

## 📌 Project Overview

The **Dynamic Employee Dashboard** is a simple and interactive web application developed using HTML, CSS, and JavaScript. It allows users to enter employee names and roles through a form and dynamically display employee information in individual cards.

The webpage features a black background, light-green employee cards, and a centered employee registration form. New employee cards are added without reloading the webpage.

## ✨ Features

- Add employees with their names and roles.
- Display employee details in dynamic cards.
- Validate form inputs before adding employees.
- Clear input fields after successful submission.
- Update the webpage dynamically without refreshing.
- Responsive design for different screen sizes.
- Simple and user-friendly interface.

## 🛠️ Technologies Used

- **HTML5** – Creates the webpage structure.
- **CSS3** – Styles the form, employee cards, colors, and responsive layout.
- **JavaScript** – Handles form submission, validation, and DOM manipulation.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter an employee name and role.
5. Click **Add Employee** to display the employee card.
